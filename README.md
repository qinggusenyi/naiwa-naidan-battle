# 奶蛙 VS 奶蛋 · 双人知识对战

双击 `index.html` 离线游玩。请将 HTML 与六张运行用 `*-play.webp` 图片放在同一文件夹。原始 PNG 和停用的 `egg-attack-play.webp` 是素材备份，游戏运行时不读取。没有账号、安装或联网依赖。

## 玩法

- 左右分别答自己的题，题号可以不同；答对立即发射攻击波，然后这一侧进入下一题。另一侧不会被迫等待。
- 双方各有 100 HP。答对造成 16 HP 伤害，连续答对第二题造成 20 HP，第三题起每题造成 25 HP。
- 答错只暂停自己 1 秒，错误选项禁用；另一侧可以继续答。
- 每局 2 分 30 秒。先耗尽对方 HP 获胜；时间结束时剩余 HP 较高者获胜。
- 点击开战后先播放约 1.6 秒的 READY → GO 开场；期间双方暂不能答题，比赛计时从 GO 结束后开始。重开、切换年级和演示模式同样播放开场。
- 英语看图选词、成语补字、数学口算按年级混合出题。每题 4 个选项，每侧尽量避开同局重复。
- “演示”会让两边自动轮流出招，便于录屏。
- 首页、对战中和结算页都能选择 1–3 年级；对战中切换年级会直接开始该年级的新一局。顶部“首页”可随时返回，结算页提供再打一局、返回首页和自动演示。

对战画面由一个 Canvas 绘制，角色平时保持静止；出招时先蓄力、再前冲并发射攻击波。奶蛙使用攻击姿态，奶蛋保持本体。命中时对手短促闪白、击退并停顿，伤害数字在画面中停留约 1.6 秒，血条旁的掉血提示停留约 2.2 秒。最后一击播完受击才进入结果页。

运行素材缩小并转成 WebP，六张实际加载图片约 680 KiB。Canvas 只在有攻击时逐帧绘制角色与特效，闲置时停止刷新；战场背景和答题区不参与逐帧重绘。

运行 `node check.cjs` 可检查题目、独立答题、伤害、连击、计时、重开和演示流程。

## 让 AI 更换题目和人物

可以把仓库链接交给有文件编辑能力的 AI，并让它直接修改 `index.html`。这是纯前端项目，改完双击 HTML 就能检查效果。建议一次只改一类内容，保留现有的双人答题、计时、血量和出招流程。

### 更换题目

- 英语词在脚本开头的 `ENGLISH` 数组，每项是 `[英文词, 图片或表情]`，例如 `['grape','🍇']`。一年级只从前 12 项抽题，二、三年级使用完整数组；想让一年级也抽到新词，就把它放进前 12 项并保持这一范围至少有 4 个不同词。
- 成语在 `IDIOMS` 数组，每项是 `[带空格的题面, 正确字, [两个干扰字]]`。程序会再补一个干扰字，组成 4 选 1。一年级只从前 8 项抽题，二、三年级使用完整数组。改题时确认成语、答案、干扰字都准确，且四个选项不会重复。
- 口算由 `mathQ()` 按 `game.grade` 生成，不在固定题库里。要调整数字范围或运算符，修改这个函数里对应年级的分支；继续保证结果适合该年级、答案是整数、4 个选项不同。
- `prepareQuestion()` 负责混合英语、成语、口算，避免同一侧连续出现相同题型，并用 `game.used` 尽量减少同局重复。要调整题型比例或加入新题型，需要同时修改这里和 `panelHTML()` 的题型标签；新题目仍需返回 `{key,type,art,prompt,choices,answer}`，`choices` 必须有 4 个不同选项且包含 `answer`。

### 更换人物和攻击效果

- 先准备透明背景的 WebP 人物图和攻击波图，放在 `index.html` 同级目录。保持人物主体完整、透明边缘干净；建议将运行用图片压缩到几百 KB 以内。场地可替换 `arena-play.webp`，建议使用宽幅图片，并在中央留出攻击波飞行空间。
- 在脚本开头的 `ACTORS` 中替换 `left`、`right` 的 `name`、`img`、`wave`、`attack`。左侧还可替换 `attackImg`；右侧目前没有独立攻击姿态，若要增加，需要同步修改 `paintBattle()` 中选择 `src` 的逻辑。
- 搜索 `index.html` 里的“奶蛙”“奶蛋”“薄荷波”“星芒波”，把标题、血条、答题面板、首页和结算页里的固定文字也改掉。首页人物缩略图在 `render()` 的 `<div class="mini">` 中；血条配色在 CSS 的 `.hp-fill.frog` / `.hp-fill.egg`，攻击光色在 `paintBattle()` 里根据 `ACTORS[side].kind` 选择。
- `paintBattle()` 中人物绘制高度左右分别约为场地高度的 79% 和 70%，角色锚点在画面约 21% 和 79%。新人物若过大、过小或位置不对，微调这里的 `height`、`x` 和 `y`。攻击波的尺寸与轨迹也在这个函数里。

可以直接复制这段话给 AI：

> 请修改 https://github.com/qinggusenyi/naiwa-naidan-battle 这个离线网页游戏。按照 README 的“更换题目和人物”说明，替换我指定的题目和人物素材；保持双人同时答题、READY → GO、攻击波、血量和演示模式。不要添加联网依赖。修改后运行 `node check.cjs`，并实际打开 `index.html` 查看人物方向、攻击波与受击效果。我的新题目／素材是：【在这里填写或附图】。

## 画面为什么比较顺畅

- 人物、攻击波和场地使用压缩后的 WebP；六张实际加载的图片合计约 680 KiB。图片在页面初始化时加载，不在每一帧重新读取文件。
- 场地是 CSS 背景，答题面板是普通 HTML；对战 Canvas 只绘制人物和攻击效果，减少每帧要重画的内容。
- `battleLoop()` 只在出招时用 `requestAnimationFrame` 更新；没有攻击时停止逐帧绘制。`paintBattle()` 根据统一的时间戳计算蓄力、飞行、命中和受击位置，减少多个动画不同步造成的跳动。
- Canvas 的像素密度上限设为 1.5 倍，避免高分辨率屏幕绘制过多像素；受击白闪图由 `whiteSprite()` 在图片加载时预先生成。
- 攻击波在 160–560 毫秒持续飞行，命中后伤害数字继续显示，角色平时静止。换素材时尽量保留这些时序和静止状态，避免给整张大图加持续模糊、滤镜或抖动。实际流畅度仍取决于设备和浏览器。

## 素材

七张图片使用内置 imagegen 工具生成，最终文件保存在本文件夹。角色提示词保留用户参考图中的奶蛙黄色梨形身体、白色肚皮、绿色眼睛、短四肢，以及奶蛋的浅黄色蛋形轮廓、绿色眼睛和微笑；攻击姿态分别是奶蛙跃起推出水浪、奶蛋倾斜蓄起金星，透明背景且保持角色身份。场地提示词为儿童友好的宽幅魔法擂台，左侧蓝绿水晶与瀑布、右侧暖色水晶与灯笼，中央留出对战空间，无角色和 UI。特效提示词分别为透明背景的薄荷水纹光刃与金色星芒彗光，水平飞行，清晰的亮色核心和拖尾。
